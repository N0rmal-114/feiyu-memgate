# 设计史

这个目录放的是 feiyu-memgate 的来源项目（一个私人的陪伴机器人）里，记忆模块的原始设计文档。它们回答的是“框架为什么长成现在这样”，不是使用手册。公开前去掉了私人信息和内部路径；文中的文件名、命令（如 `xfy ...`）和部署细节属于来源项目，不是本仓库的接口。

怎么读：

1. [2026-11-12-origin-audit.md](2026-11-12-origin-audit.md)：重新设计之前对旧记忆模块做的只读调研，列出 18 个带证据的问题。想知道框架在解决什么，先读这篇。
2. [2026-11-12-memory-redesign.md](2026-11-12-memory-redesign.md)：针对这些问题的重新设计，分 5 块，包含主人的原话要求和逐条定下的决定。只有第 1 块（底层修复）做了，第 2–5 块只有已定的规则。
3. [2026-11-08-self-memory.md](2026-11-08-self-memory.md)：智能体自己的私密记忆（加密、自己决定写什么）的设计。还没实现，重新设计的第 5 块以它为底稿。

在本仓库里写的设计说明（不是来源项目的文档）：

- [2026-11-14-forgetting-curve.md](2026-11-14-forgetting-curve.md)：遗忘曲线的设计和两次修订。
- [2026-11-17-chat-experience.md](2026-11-17-chat-experience.md)：聊天体验的第一轮改进：不重复给同一条记忆、时间感、写入说明、自动记录的过滤、召回失败的提示，以及留到后面的几项。
- [2026-11-18-linked-recall.md](2026-11-18-linked-recall.md)：关联召回：从交出去的最前几条记忆再走一步，把连着它们的记忆一起带回来。试过的几种做法在开发集和留出集上的结果、采用哪一种、为什么，以及没解决的问题。
- [2026-11-18-recall-with-a-model.md](2026-11-18-recall-with-a-model.md)：让模型帮着联想的三种办法（用回复再查一次、先推断需要再查、写入时加联想线索）在扩大后的测试题上的测量。只有测量，没有进入产品。
- [2026-11-18-sessions.md](2026-11-18-sessions.md)：多轮对话里的召回。每个世界加了三段写好的对话，按轮回放，量晚一轮到的记忆还用不用得上、历史被压缩之后怎么办、隔天新开对话能不能接上。只有测量。
- [2026-11-21-noise.md](2026-11-21-noise.md)：无关的记忆。按分数过滤的四种规则基本不管用；把交给模型的说明写严、或者让模型先挑一遍，才明显减少无关记忆进到回复里。只有测量。
- [2026-11-22-reply-quality.md](2026-11-22-reply-quality.md)：回复本身有没有变好。把每个配置的回复和基线的回复配成对盲评；同一份输入写两次的差别就很大，几项实验设置都没有量出站得住的改进。只有测量。
- [2026-11-22-audience-levels.md](2026-11-22-audience-levels.md)：受众级别。存储声明给谁看，客户端声明被谁看，对不上时网关拒绝启动；客户端可以发送 `context`。
- [2026-11-22-explained-recall.md](2026-11-22-explained-recall.md)：解释召回。一个只读的请求，说明每条候选的去向和去掉它的步骤；只给主人级的客户端，不算一次使用。DSH 插件的设置页面用它做了“试一下召回”。

- 文中说的 OpenViking、AstrBot、DeepSeek 是来源项目用到的组件，本仓库把存储换成了可替换的“后端”，见 [架构说明](../architecture.md)。
- 文档除公开前的删节外保持原样，没有改写；已经做、没做、以及还想做的事，整理在 [路线图](../roadmap.md)。
